# 章鱼 AI 全景分析

全网 AI 调研境内境外数据，由多个大模型混合部署。页面参考「电子杂志 × 电子墨水」风格，适合手机和微信竖版阅读：浅灰纸张背景、黑色正文、荧光绿标题与重点标记，所有内容保持紧凑的小字号和单列长页面结构。

## 快速预览

```bash
python3 server.py
# 打开 http://localhost:4173
```

也可以只预览静态页面：

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## 页面与推送内容

- 标题：**章鱼 AI 全景分析**
- 副标题：全网 AI 调研境内境外数据，由多个大模型混合部署。
- 竖版简报使用浅灰背景、黑色正文、荧光绿标题和黑底荧光绿重点。
- 报告标题不展示推送渠道或推送时间。
- **开头「AI 今天给你去噪音，留干货」总结不再硬编码**：由 `analyze_brief()` 依据当日真实抓取标题动态计算，每次推送随数据更新。开篇板块给出四个观点：① 市场情绪（偏多/偏空/中性 + 情绪描述）② 多空博弈概率（多/空百分比 + 信号样本量）③ 利好板块 / 利差板块（按各板块净多、净空信号排序）④ 资金流向分析（净流入主线 + 遭回避方向）。
- 正文末尾保留调研说明、免责声明与作者署名：**作者：章鱼 ai　　仅供参考，分析研究**。
- `sources.py` 生成内联样式 HTML，可直接用于微信阅读和 PushPlus HTML 模板。
- `index.html` 是带数据源、计划和手动推送操作的本地管理页。

## 数据与推送

脚本会抓取 18 个数据源，网络不可用时自动使用内置演示数据。配置 `PUSHPLUS_TOKEN` 后，可通过 GitHub Actions 或本地服务执行推送：

```bash
PUSHPLUS_TOKEN=xxx python3 push_brief.py
```

数据仅供参考，不构成投资建议。
