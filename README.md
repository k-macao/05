# 章鱼 AI 全景分析

全网 AI 调研境内境外数据，由多个大模型混合部署。页面参考「电子杂志 × 电子墨水」风格，适合手机和微信竖版阅读：浅灰纸张背景、黑色正文、荧光绿标题与重点标记，所有内容保持紧凑的小字号和单列长页面结构。

## 快速预览

```bash
python3 server.py
# 打开 http://localhost:4173
```

也可以只预览静态页面：

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## 页面与推送内容

- 标题：**章鱼 AI 全景分析**
- 副标题：全网 AI 调研境内境外数据，由多个大模型混合部署。
- 竖版简报使用浅灰背景、黑色正文、荧光绿标题和黑底荧光绿重点。
- 报告标题不展示推送渠道或推送时间。
- **开头「AI 每日总结」不再硬编码**：由 `analyze_brief()` 依据当日真实抓取标题动态计算，每次推送随数据更新。开篇板块给出四个观点：① 市场情绪（偏多/偏空/中性 + 情绪描述）② 多空博弈概率（多/空百分比 + 信号样本量）③ 利好板块 / 利差板块（按各板块净多、净空信号排序）④ 资金流向分析（净流入主线 + 遭回避方向）。
- **开头新增「AI 研判」板块**：按六维度内容策略用 AI 复盘最新的 A 股行情——① 三大指数涨跌（上证/深成/创业板/科创50 收盘与涨幅）② 两市成交额（量能 + 放量/缩量解读）③ 涨跌家数与涨跌停（广度 + 涨停/跌停 + 封板率 + 连板高度）④ 领涨 / 领跌板块（主线与退潮方向）⑤ 主力资金与北向资金（净流入主线；北向实时数据 2024 年 8 月起已停止披露，以主力与两融口径观察）⑥ 后市观点与策略（AI 研判 + 催化 + 机构观点）。数据链路：东方财富公开行情接口（主源，指数日 K、涨停/跌停池均按日回溯）优先抓取 → 腾讯证券行情接口（备用源，主源失联/缺指数时自动补位）→ 内置真实快照兜底，无网络环境同样稳定出内容。详见 `docs/ashare_review.md`。
- **开头新增「AI 板块机会」板块**：与「AI 每日总结」共用同一套多空信号统计。「机会方向」按 信号强度 × 跨源热度 排序列出净多头板块 Top 4，每个板块给出净多计数、命中源数 / 提及条数，以及最多 3 条支撑新闻证据（标注来源数据源、方向相符的证据优先）；「承压方向」单列净空头板块 Top 2（每个最多 2 条证据）作为资金回避方向。当日样本无净多头信号时诚实标注「暂无净多头信号占优的板块」，不编造结论。
- 正文末尾保留调研说明、免责声明与作者署名：**作者：章鱼 ai　　仅供参考，分析研究**。
- `sources.py` 生成内联样式 HTML，可直接用于微信阅读和 PushPlus HTML 模板。
- `index.html` 是带数据源、计划和手动推送操作的本地管理页。

## 数据与推送

脚本会抓取 18 个数据源，网络不可用时自动使用内置演示数据。配置 `PUSHPLUS_TOKEN` 后，可通过 GitHub Actions 或本地服务执行推送：

```bash
PUSHPLUS_TOKEN=xxx python3 push_brief.py
```

**推送前大盘数据新鲜度检查（不是最新就不推）**：推送前会先确认简报里的「AI 研判」数据为最新——①行情接口可用（东方财富主源与腾讯证券备用源至少一个可用）；②接口数据不滞后（最新日 K 不早于内置快照基线）；③复盘数据来自实时接口（东方财富或腾讯证券备用源，非内置快照兜底）且复盘日等于最近一个可复盘交易日。任何一条不满足即放弃本次推送：`push_brief.py` 退出码 3（GitHub Actions 显示为失败，便于发现行情源异常），本地服务 `POST /api/run` 返回 409 并透出具体原因。页面「AI 研判」标题右侧的标签实时展示该检查结果（`GET /api/market`）。

相关环境变量（测试/应急/会员扩展）：

- `PUSHPLUS_MEMBER=1`：开通 PushPlus 会员后配置，解锁 10 万字推送上限与全量快讯展示（普通用户默认上限 2 万字，精选展示）。
- `SKIP_MARKET_CHECK=1`：跳过新鲜度检查，直接推送。
- `MARKET_FRESHNESS_FORCE=fresh|stale`：强制检查结果，用于联调测试。

数据仅供参考，不构成投资建议。
